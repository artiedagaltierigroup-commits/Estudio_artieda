# Ahorros Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build the Ahorros screen with savings goals, contributions, progress states, quick filters, and automatic expense impact.

**Architecture:** Add Drizzle tables for savings goals and contributions. Contributions create linked `expenses` rows with origin `SAVINGS`, so existing financial summaries continue working. The UI is a server-rendered dashboard route with small client forms for creation and contribution.

**Tech Stack:** Next.js App Router, React 19, Drizzle ORM, Postgres/Supabase RLS, Vitest, Tailwind, lucide-react.
